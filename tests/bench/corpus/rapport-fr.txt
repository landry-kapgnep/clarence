INTRODUCTION

C'est en septembre que j'ai commencé mon stage de deuxième année chez Korrigane
Labs, une jeune entreprise installée à Nantes. Amandine ROUSSEAU, c'est moi, et
je suis étudiante à l'IUT de Villetaneuse.

L'entreprise développe une solution d'extraction de candidatures. Sa pile
technique repose sur Python, Docker et PostgreSQL, avec du React côté interface.
Nous utilisons GitHub pour la revue de code et Slack pour la communication.

3) EXÉCUTION DES TÂCHES

Ma première mission a consisté à concevoir un script d'anonymisation. J'ai
utilisé la bibliothèque Faker pour générer de fausses données. Le script tourne
en local, sans jamais envoyer de données personnelles à une API externe.

La deuxième mission portait sur la vérité terrain : une référence faite à la
main pour mesurer les erreurs du modèle. J'ai travaillé avec Nadia Belkacem sur
environ 150 bulletins.

CONCLUSION

Ce stage m'a beaucoup appris, techniquement et humainement. Le code que j'ai
écrit continue de servir à l'équipe.
